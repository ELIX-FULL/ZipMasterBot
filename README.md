# 📦 ZipMasterBot

A simple but powerful Telegram bot that collects any type of files (documents, photos, videos, audios, stickers, voice messages, etc.), packs them into a `.zip` archive, and sends it back to the user.  
Built with **Python + Telebot**.

## ✨ Features
- 📂 Collect **unlimited files** from the user
- 📸 Supports **media groups** (multiple files in one message)
- 🖼 Supports **all file types** Telegram can send: documents, videos, photos, audios, voice, video notes, stickers, GIFs
- 🏷 Allows you to set a **custom ZIP filename**
- 📝 Lets you add a **caption** before sending the archive
- 🔄 Automatically **deletes temporary files** after sending to save memory
- 🖌 Beautiful UX with **emojis and stickers**
